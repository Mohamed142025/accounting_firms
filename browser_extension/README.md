# Accounting Firms Auto Login (إضافة المتصفح)

إضافة Chrome / Edge بتكمّل زرار "فتح المنصة" في شاشة العميل في ERPNext: بتفتح صفحة الدخول
وتعبّي اسم المستخدم وكلمة المرور وتضغط دخول تلقائيًا.

## التسطيب (مرة واحدة على كل جهاز)

1. نزّل الملف: `https://<your-site>/assets/accounting_firms/extension/accounting-firms-auto-login.zip`
2. فك الضغط في مجلد ثابت (مثلاً `C:\accounting-firms-extension`). متمسحش المجلد بعدها.
3. افتح `chrome://extensions` (أو `edge://extensions`).
4. فعّل **Developer mode** من أعلى اليمين.
5. اضغط **Load unpacked** واختار المجلد.

## الاستخدام

افتح العميل في ERPNext ← تاب Tax ← جدول "حسابات المنصات الضريبية" ← افتح الصف ← "فتح المنصة".

## ضبط منصة

لو منصة ما اتعبتش تلقائيًا، افتح سجلها في **Tax Platform** ← قسم "إعدادات الدخول التلقائي"
واكتب الـ CSS selectors لحقول اسم المستخدم وكلمة المرور وزر الدخول. من غيرهم الإضافة بتحاول
تتعرف على الحقول بنفسها.

## الأمان

- كلمة المرور بتتبعت من ERPNext للإضافة داخل نفس المتصفح فقط، ومش بتتخزن على القرص.
- البيانات بتتمسح من ذاكرة الإضافة بعد الدخول أو بعد 3 دقائق.
- الإضافة ما بتبعتش أي بيانات لأي جهة خارجية.
